# Prompts

Paste-and-edit copy. Not slash-invoked. The point is **visible prompting craft** — moments when you type into the chat directly so the work shows.

When you want the agent to do something and the interviewer should see *how* you're shaping the work, paste a prompt from here, edit the bracketed parts, and send.

| Prompt | Use when |
|---|---|
| `kickoff-feature.md` | Starting a new feature. Paste, edit, send. The agent reads it and runs the right skill. |
| `idealization-probes.md` | You want the agent to grill you with a specific shape of question (Who/Problem/Success/Constraints/Ruled-out). |
| `grill-personas.md` | You want the agent to roleplay UX/QA/TechLead and produce concerns from each angle. |
| `manual-test-customize.md` | You want a custom manual test guide for an unusual flow. |

## When to use a prompt vs a skill

- **Skill** — repeatable mechanical work, multi-step procedure, you'd run it the same way every time.
- **Prompt** — bespoke moment where the framing matters, the wording is the craft, and the interviewer should see you thinking.
